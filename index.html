Dán thông tin từ Firebase Console → Project Settings → Your apps → Web app:
📋 Hướng dẫn tạo Firebase miễn phí →
1️⃣ Vào console.firebase.google.com
2️⃣ Tạo project mới → đặt tên → bỏ Google Analytics
3️⃣ Vào Build → Realtime Database → Create database → chọn region → bắt đầu ở test mode
4️⃣ Vào Project Settings ⚙️ → tab General → kéo xuống Your apps → thêm Web app </>
5️⃣ Copy apiKey và databaseURL dán vào 2 ô trên
6️⃣ Nhấn Lưu & Kết nối — xong! 🎉
